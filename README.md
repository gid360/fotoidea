# 📸 Fotoidea CRM — Система управления студией

**Fotoidea CRM** — современная полнофункциональная CRM-система для автоматизации фотостудий, фитнес-студий и творческих пространств. Система обеспечивает полный цикл управления: от онлайн-записи клиентов и расписания залов до кассового учёта, расчёта зарплат персонала и автоматических уведомлений в WhatsApp.

---

## 🚀 Ключевые возможности

### 📅 Расписание и Управление Записями
- **Интерактивная сетка залов**: отображение занятости залов и направлений в реальном времени.
- **Гибкая настройка бронирования**: учёт стоимости услуг, предоплат, доплат за количество гостей и аренду гардероба.
- **Статусы записей**: *Не подтверждён*, *Подтверждён*, *Пришёл*, *Не пришёл*, *Отменён*.
- **Назначение исполнителей**: привязка фотографов / тренеров к занятиям и съёмкам.

### 👥 База Клиентов & Лояльность
- **Подробные карточки клиентов**: история визитов, баланс депозита, сумма общих продаж, заметки.
- **Автоматическое тегирование (Loyalty System)**:
  - `NEW` (Новый client — первая запись);
  - `REGULAR` (Постоянный — 3+ визитов за последние 45 дней);
  - `LOST` (Потерянный — от 30 дней без визитов).
- **Документы и фото**: сканирование документов, снимки с веб-камеры, прикрепление файлов к профилю.

### 💰 Кассовый Модуль и Финансы
- **Управление кассовыми сменами**: открытие и закрытие смен, ввод фактического остатка, автоматическая сверка с системным балансом и фиксация расхождений.
- **Учёт операций**: приходы (продажа абонементов, сертификатов, пополнение депозита) и расходы (зарплата, хозрасходы, возвраты).
- **Гибкие способы оплаты**: *Наличные*, *Карта / QR*, *Списание с депозита*, *Смешанная оплата*.

### 🎁 Подарочные Сертификаты
- **Типы сертификатов**:
  - **Номинальный** — фиксированная сумма для зачисления на депозит клиента;
  - **Пакетный** — привязка к конкретной услуге или абонементу.
- **Генерация брендированных PDF**: автоматическое формирование PDF-файлов с уникальным кодом и QR-кодом для печати или отправки клиенту.
- **Кастомизация**: указание отправителя, получателя и персонального поздравления.

### 💵 Расчёт Зарплаты Персонала
- **Различные схемы начисления зарплат**:
  - **Фиксированная** ставка за факт проведения;
  - **Процентная** ставка от стоимости съёмки;
  - **Подушная** оплата за каждого пришедшего клиента;
  - **Гибридная** модель (фикса + бонус за клиента).
- **Автоматический учёт выплат** и детализированные отчёты по каждому сотруднику.

### 📊 CRM & Воронка Продаж
- **Управление лидами**: этапы воронки (*Новое обращение*, *Квалификация*, *Записан на пробное*, *Посетил*, *Купил*, *Проиграно*).
- **Источники обращений**: WhatsApp, Instagram Direct, Онлайн-виджет, Ручной ввод.
- **Аудит изменений**: история действий сотрудников по клиентам, записям и сделкам.

### 💬 Интеграция с WhatsApp (Evolution API)
- **Автоматические уведомления**: подтверждение записи, напоминания за X часов до визита, поздравления с днём рождения.
- **Очередь сообщений**: надежная доставка, дедупликация и отслеживание статусов отправки (*QUEUED*, *SENT*, *ERROR*).

### 🌐 Виджет Онлайн-Записи
- **Публичная форма для клиентов**: адаптивный интерфейс самостоятельного бронирования времени и залов без необходимости звонка администратору.

### 🔄 Импорт данных из Altegio
- Модуль быстрой миграции клиентской базы и истории записей из системы Altegio.

### 🔐 Разграничение прав доступа (RBAC)
- `SUPERADMIN` — полный доступ к настройкам, финансам и аналитике;
- `ADMIN` — доступ к кассе, расписанию, клиентам и сертификатам;
- `TRAINER` — просмотр личного расписания и отметка посещаемости;
- `PHOTOGRAPHER` — просмотр съёмок и проведение записей.

## 🛠 Технологический стек

- **Frontend**: [Next.js 16](https://nextjs.org/) (App Router), [React 19](https://react.dev/), [TailwindCSS](https://tailwindcss.com/), [Radix UI](https://www.radix-ui.com/), Lucide Icons, TanStack Query v5.
- **Backend**: Next.js API Routes, NextAuth.js.
- **База данных и ORM**: [PostgreSQL](https://www.postgresql.org/), [Prisma ORM 5](https://www.prisma.io/).
- **Генерация документов**: `pdf-lib`, `@pdf-lib/fontkit`, `qrcode`.
- **Интеграции**: Evolution API (WhatsApp), Vercel Blob.

## 🚦 Быстрый старт

### 1. Предварительные требования
- **Node.js** v18.0 или выше
- **PostgreSQL** v14 или выше
- **npm** или **pnpm** / **yarn**

### 2. Клонирование репозитория
```bash
git clone https://github.com/gid360/fotoidea.git
cd fotoidea
```

### 3. Установка зависимостей
```bash
npm install
```

### 4. Настройка переменных окружения
Создайте файл `.env` на основе `.env.example`:
```bash
cp .env.example .env
```
Заполните параметры подключения к базе данных PostgreSQL и секретные ключи:
```env
DATABASE_URL="postgresql://user:password@localhost:5432/fotoidea_db?schema=public"
NEXTAUTH_SECRET="your-super-secret-key"
NEXTAUTH_URL="http://localhost:3002"
```

### 5. Инициализация базы данных
Примените миграции Prisma и заполните БД первичными данными:
```bash
npm run db:push
npm run db:seed
```

### 6. Запуск сервера разработки
```bash
npm run dev
```
Приложение будет доступно по адресу: **http://localhost:3002**

## 📜 Основные npm-скрипты

| Скрипт | Описание |
| :--- | :--- |
| `npm run dev` | Запуск сервера разработки Next.js на порту 3002 |
| `npm run build` | Применение схемы БД и сборка продакшен-бандла |
| `npm run start` | Запуск собранного продакшен-сервера |
| `npm run db:push` | Синхронизация схемы Prisma с базой данных |
| `npm run db:seed` | Заполнение базы данных начальными справочниками |
| `npm run db:studio` | Запуск графического веб-интерфейса Prisma Studio |
